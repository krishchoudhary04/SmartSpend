# SmartSpend — Personal Expense Tracker

SmartSpend is a beginner-friendly Python terminal application that helps users manage and track their daily expenses.

## Features

- Add new expenses
- View all recorded expenses
- Calculate total spending
- Edit existing expenses
- Delete expenses
- View category-wise spending
- Save and load expense data using JSON
- Handle invalid user input

## Tech Stack

- **Language:** Python
- **Data Storage:** JSON
- **Concepts:** Lists, dictionaries, loops, functions, exception handling, file handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   'python main.py'

## Data Storage

The application stores expense records in 'expenses.json'.If the file does not exist, the application creates it when saving expenses.Keep this file in the appropriate project directory so saved expenses can be loaded when the application starts.

Building SmartSpend helped me practise Python programming, CRUD operations (Create, Read, Update, Delete), input validation, and JSON-based data persistence.
